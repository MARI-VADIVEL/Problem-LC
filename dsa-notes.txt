
========================================
DSA TOPIC: Array
========================================

Explanation:
An array is a linear data structure that stores elements in contiguous memory locations. Each element is accessed using an index. The first element is at index 0. Array access is O(1), while searching an unsorted array takes O(n).

Example:
Example: int[] arr = {10,20,30,40}; arr[2] gives 30.


========================================
DSA TOPIC: Array Traversal
========================================

Explanation:
Array traversal means visiting every element of an array one by one. A loop is commonly used to process each element. The operation takes O(n) time because every element may need to be visited.

Example:
Example: for each element in [10,20,30], process 10, then 20, then 30.


========================================
DSA TOPIC: Two Pointer Technique
========================================

Explanation:
The two pointer technique uses two indices to process an array or string efficiently. The pointers can move toward each other or in the same direction depending on the problem. It can reduce an O(n^2) approach to O(n) in many cases.

Example:
Example: In a sorted array, left starts at the beginning and right starts at the end.


========================================
DSA TOPIC: Sliding Window
========================================

Explanation:
Sliding window maintains a range of elements while moving through an array or string. Instead of repeatedly calculating the same range, the window is updated as it moves. This often gives O(n) solutions.

Example:
Example: For a fixed window size of 3, move the window one position at a time while updating its sum.


========================================
DSA TOPIC: Prefix Sum
========================================

Explanation:
A prefix sum stores cumulative sums of an array. It allows range-sum queries to be answered quickly after preprocessing. Building the prefix array takes O(n) time.

Example:
Example: For [2,4,6], the prefix sums are [2,6,12].


========================================
DSA TOPIC: Kadane Algorithm
========================================

Explanation:
Kadane's algorithm finds the maximum sum of a contiguous subarray. It keeps track of the best sum ending at the current position and the overall best sum. Its time complexity is O(n).

Example:
Example: In [-2,1,-3,4,-1,2,1], the maximum subarray is [4,-1,2,1].


========================================
DSA TOPIC: Binary Search
========================================

Explanation:
Binary search works on a sorted collection by repeatedly dividing the search space into two halves. If the target is smaller or larger than the middle value, one half is discarded. Time complexity is O(log n).

Example:
Example: Searching for 30 in [10,20,30,40,50] checks the middle before choosing the correct half.


========================================
DSA TOPIC: Linear Search
========================================

Explanation:
Linear search checks elements sequentially until the target is found or the array ends. It works even when the data is unsorted. Its worst-case time complexity is O(n).

Example:
Example: Searching for 30 in [10,20,30,40] checks 10, then 20, then 30.


========================================
DSA TOPIC: Sorting
========================================

Explanation:
Sorting arranges data according to a particular order, usually ascending or descending. Sorted data can make searching and other operations easier. Different sorting algorithms have different time and space requirements.

Example:
Example: [5,2,4,1] becomes [1,2,4,5] in ascending order.


========================================
DSA TOPIC: Bubble Sort
========================================

Explanation:
Bubble sort repeatedly compares adjacent elements and swaps them when they are in the wrong order. Larger elements gradually move toward the end. Its average and worst-case time complexity is O(n^2).

Example:
Example: During one pass, the largest unsorted element moves to the right side.


========================================
DSA TOPIC: Selection Sort
========================================

Explanation:
Selection sort repeatedly finds the smallest element from the unsorted portion and places it at the beginning. It performs O(n^2) comparisons and uses O(1) extra space.

Example:
Example: From [4,2,1,3], select 1 and place it at the first position.


========================================
DSA TOPIC: Insertion Sort
========================================

Explanation:
Insertion sort builds the sorted portion one element at a time. Each new element is inserted into its correct position among previously sorted elements. Its worst-case time complexity is O(n^2).

Example:
Example: It works similarly to arranging playing cards in your hand.


========================================
DSA TOPIC: Merge Sort
========================================

Explanation:
Merge sort divides an array into smaller parts, sorts those parts, and merges them. It follows the divide-and-conquer approach. Its time complexity is O(n log n) and it normally requires O(n) extra space.

Example:
Example: [4,1,3,2] is divided into smaller arrays and then merged in sorted order.


========================================
DSA TOPIC: Quick Sort
========================================

Explanation:
Quick sort selects a pivot and partitions the array so that smaller values go to one side and larger values go to the other. The partitions are then sorted recursively. Average time complexity is O(n log n).

Example:
Example: With 5 as pivot, values smaller than 5 are placed before it.


========================================
DSA TOPIC: Hashing
========================================

Explanation:
Hashing maps keys to locations using a hash function. Hash tables provide average O(1) insertion, deletion, and lookup. Hashing is useful for frequency counting and fast membership checking.

Example:
Example: A HashSet can quickly determine whether a value already exists.


========================================
DSA TOPIC: HashSet
========================================

Explanation:
A HashSet stores unique elements and does not allow duplicates. It uses hashing internally and provides average O(1) lookup, insertion, and deletion.

Example:
Example: Adding 10 twice to a HashSet still leaves only one 10.


========================================
DSA TOPIC: HashMap
========================================

Explanation:
A HashMap stores data as key-value pairs. It is commonly used for frequency counting, lookup tables, and mapping relationships. Average insertion and lookup are O(1).

Example:
Example: map.put("apple",3) stores apple with frequency 3.


========================================
DSA TOPIC: String
========================================

Explanation:
A string is a sequence of characters. Strings are widely used in pattern matching, searching, parsing, and many interview problems. In Java, String objects are immutable.

Example:
Example: String s = "hello" contains five characters.


========================================
DSA TOPIC: StringBuilder
========================================

Explanation:
StringBuilder is used to create and modify strings efficiently. Unlike String, it is mutable, so repeated modifications do not require creating many new String objects.

Example:
Example: StringBuilder can append characters repeatedly while constructing a result.


========================================
DSA TOPIC: Palindrome
========================================

Explanation:
A palindrome is a sequence that reads the same from both directions. A common method uses two pointers starting from opposite ends and compares characters.

Example:
Example: "level" is a palindrome because it reads the same forward and backward.


========================================
DSA TOPIC: Anagram
========================================

Explanation:
Two strings are anagrams when they contain the same characters with the same frequencies, possibly in different orders. Frequency arrays or hash maps can be used to check anagrams.

Example:
Example: "listen" and "silent" are anagrams.


========================================
DSA TOPIC: Frequency Counting
========================================

Explanation:
Frequency counting records how many times each value or character occurs. HashMap or arrays are commonly used for this technique. It can turn repeated searching into a single pass.

Example:
Example: In [1,2,2,3,3,3], the frequency of 3 is 3.


========================================
DSA TOPIC: Linked List
========================================

Explanation:
A linked list consists of nodes where each node stores data and a reference to another node. Unlike arrays, linked-list nodes do not need contiguous memory.

Example:
Example: 10 -> 20 -> 30 -> null represents a simple singly linked list.


========================================
DSA TOPIC: Singly Linked List
========================================

Explanation:
A singly linked list node contains data and a reference to the next node. Traversal normally starts from the head and moves through next references.

Example:
Example: head -> 10 -> 20 -> 30 -> null.


========================================
DSA TOPIC: Reverse Linked List
========================================

Explanation:
Reversing a linked list changes every next reference so that the nodes point toward the previous node. The standard iterative solution uses previous, current, and next references and takes O(n) time.

Example:
Example: 1 -> 2 -> 3 becomes 3 -> 2 -> 1.


========================================
DSA TOPIC: Fast and Slow Pointers
========================================

Explanation:
Fast and slow pointers use two references moving at different speeds. This technique is useful for finding the middle of a linked list and detecting cycles.

Example:
Example: slow moves one step while fast moves two steps.


========================================
DSA TOPIC: Cycle Detection
========================================

Explanation:
Floyd's cycle detection algorithm uses fast and slow pointers. If the linked list contains a cycle, the two pointers eventually meet. The algorithm uses O(n) time and O(1) extra space.

Example:
Example: 1 -> 2 -> 3 -> 2 creates a cycle.


========================================
DSA TOPIC: Merge Two Sorted Lists
========================================

Explanation:
Two sorted linked lists can be merged by comparing their current nodes and repeatedly choosing the smaller value. A dummy node simplifies the construction of the result.

Example:
Example: [1,3,5] and [2,4,6] become [1,2,3,4,5,6].


========================================
DSA TOPIC: Stack
========================================

Explanation:
A stack follows the LIFO principle, meaning the last element inserted is the first one removed. Common operations are push, pop, and peek.

Example:
Example: Browser back operations can be modeled using a stack.


========================================
DSA TOPIC: Queue
========================================

Explanation:
A queue follows the FIFO principle, meaning the first element inserted is the first one removed. Queues are commonly used in scheduling and BFS traversal.

Example:
Example: People standing in a line are processed from the front first.


========================================
DSA TOPIC: Deque
========================================

Explanation:
A deque, or double-ended queue, allows insertion and deletion from both ends. It can be used to implement sliding-window algorithms efficiently.

Example:
Example: Elements can be added or removed from either the front or the back.


========================================
DSA TOPIC: Recursion
========================================

Explanation:
Recursion occurs when a function calls itself to solve smaller versions of the same problem. Every recursive solution needs a base case to stop the calls.

Example:
Example: Factorial of n can be defined as n multiplied by factorial of n-1.


========================================
DSA TOPIC: Backtracking
========================================

Explanation:
Backtracking builds a solution step by step and removes a choice when that choice cannot lead to a valid solution. It is commonly used for subsets, permutations, combinations, and constraint problems.

Example:
Example: Generate a subset, explore it, then remove the selected element before trying another choice.


========================================
DSA TOPIC: Subsets
========================================

Explanation:
The subset problem generates all possible selections of elements from a collection. Backtracking can choose either to include or exclude each element.

Example:
Example: [1,2] has [], [1], [2], and [1,2] as its subsets.


========================================
DSA TOPIC: Permutations
========================================

Explanation:
A permutation represents an arrangement of elements in a particular order. Backtracking can choose an unused element at each level and continue until all positions are filled.

Example:
Example: [1,2,3] has permutations such as [1,2,3] and [3,2,1].


========================================
DSA TOPIC: Binary Tree
========================================

Explanation:
A binary tree is a hierarchical data structure where each node can have at most two children called left and right.

Example:
Example: A root node 10 can have children 5 and 15.


========================================
DSA TOPIC: Tree Traversal
========================================

Explanation:
Tree traversal means visiting every node of a tree according to a particular order. Common depth-first traversals are preorder, inorder, and postorder.

Example:
Example: Inorder traversal visits left subtree, root, and right subtree.


========================================
DSA TOPIC: BFS
========================================

Explanation:
Breadth-first search explores a graph or tree level by level. It normally uses a queue and is useful for finding the shortest number of edges in an unweighted graph.

Example:
Example: Starting from a root, BFS visits all immediate neighbors before moving deeper.


========================================
DSA TOPIC: DFS
========================================

Explanation:
Depth-first search explores as far as possible along one path before backtracking. It can be implemented using recursion or an explicit stack.

Example:
Example: DFS can visit one branch of a tree completely before exploring another branch.


========================================
DSA TOPIC: Graph
========================================

Explanation:
A graph consists of vertices and edges that represent relationships between objects. Graphs may be directed or undirected and may contain weighted edges.

Example:
Example: Cities can be represented as vertices and roads as edges.


========================================
DSA TOPIC: Adjacency List
========================================

Explanation:
An adjacency list stores the neighbors of every graph vertex. It is memory efficient for sparse graphs and is commonly used with BFS and DFS.

Example:
Example: If 1 connects to 2 and 3, the list for 1 contains 2 and 3.


========================================
DSA TOPIC: Topological Sort
========================================

Explanation:
Topological sorting produces an ordering of vertices in a directed acyclic graph such that every directed edge points from an earlier vertex to a later vertex. It is useful for dependency problems.

Example:
Example: A course prerequisite can appear before the course that depends on it.


========================================
DSA TOPIC: Dynamic Programming
========================================

Explanation:
Dynamic programming solves problems by breaking them into overlapping subproblems and storing previously computed results. It can avoid repeated calculations and improve time complexity.

Example:
Example: Fibonacci values can be stored instead of recalculating the same values.


========================================
DSA TOPIC: Memoization
========================================

Explanation:
Memoization is a top-down dynamic programming technique. Results of recursive subproblems are stored so that the same state does not need to be calculated again.

Example:
Example: Store the result of fibonacci(5) so future calls can reuse it.


========================================
DSA TOPIC: Tabulation
========================================

Explanation:
Tabulation is a bottom-up dynamic programming technique. It starts with smaller known states and fills a table until the required answer is reached.

Example:
Example: A DP array can store Fibonacci values from 0 up to n.


========================================
DSA TOPIC: Greedy Algorithm
========================================

Explanation:
A greedy algorithm makes the best-looking local choice at each step with the goal of producing an optimal solution. Greedy methods work only when the problem has the required properties.

Example:
Example: Selecting activities with the earliest finishing time is a classic greedy strategy.


========================================
DSA TOPIC: Time Complexity
========================================

Explanation:
Time complexity describes how the running time of an algorithm grows as the input size increases. Common complexities include O(1), O(log n), O(n), O(n log n), and O(n^2).

Example:
Example: A single loop over n elements normally has O(n) time complexity.


========================================
DSA TOPIC: Space Complexity
========================================

Explanation:
Space complexity describes the extra memory required by an algorithm as input size grows. It includes data structures, recursion stack usage, and other auxiliary memory.

Example:
Example: An algorithm using only a few variables has O(1) auxiliary space.


========================================
DSA TOPIC: Prefix Maximum
========================================

Explanation:
A prefix maximum stores the largest value seen from the beginning of an array up to each position. It is useful when a problem requires comparing an element with values that appeared earlier.

Example:
Example: For [3,1,5,2], prefix maximum values are [3,3,5,5].


========================================
DSA TOPIC: Suffix Maximum
========================================

Explanation:
A suffix maximum stores the largest value from each position to the end of an array. It is useful for problems involving elements on the right side.

Example:
Example: For [3,1,5,2], suffix maximum values are [5,5,5,2].


========================================
DSA TOPIC: Prefix Minimum
========================================

Explanation:
A prefix minimum stores the smallest value encountered from the beginning up to each index. It helps answer minimum-value queries efficiently.

Example:
Example: For [4,2,5,1], prefix minimum values are [4,2,2,1].


========================================
DSA TOPIC: Suffix Minimum
========================================

Explanation:
A suffix minimum stores the smallest value from each index to the end of an array. It is useful when comparing an element with values to its right.

Example:
Example: For [4,2,5,1], suffix minimum values are [1,1,1,1].


========================================
DSA TOPIC: Difference Array
========================================

Explanation:
A difference array stores changes between consecutive elements. It allows multiple range updates to be performed efficiently and the final values can be reconstructed using prefix sums.

Example:
Example: Adding 5 to a range can be represented by changing only the range boundaries.


========================================
DSA TOPIC: Dutch National Flag
========================================

Explanation:
The Dutch National Flag algorithm partitions an array containing three different values into three sections. It uses multiple pointers and processes the array in O(n) time.

Example:
Example: [2,0,1,2,1,0] can be rearranged into [0,0,1,1,2,2].


========================================
DSA TOPIC: Majority Element
========================================

Explanation:
A majority element is an element that appears more than half of the array length. Moore's Voting Algorithm can find it using O(n) time and O(1) extra space.

Example:
Example: In [2,2,1,2,3,2,2], the majority element is 2.


========================================
DSA TOPIC: Moore Voting Algorithm
========================================

Explanation:
Moore's Voting Algorithm maintains a candidate and a counter. Equal values increase the counter while different values decrease it. The remaining candidate can be verified afterward.

Example:
Example: Repeated occurrences of a majority value allow its counter to survive other values.


========================================
DSA TOPIC: Kadane With Indices
========================================

Explanation:
Kadane's algorithm can be extended to track the starting and ending indices of the maximum-sum subarray. This provides both the maximum sum and the actual subarray.

Example:
Example: For [1,-2,3,4], the best range is indices 2 to 3.


========================================
DSA TOPIC: Stock Buy and Sell
========================================

Explanation:
The single-transaction stock problem can be solved by tracking the minimum price seen so far and calculating the profit from selling at each later price. It takes O(n) time.

Example:
Example: Prices [7,1,5,3,6,4] give maximum profit 5.


========================================
DSA TOPIC: Best Time Multiple Transactions
========================================

Explanation:
When multiple stock transactions are allowed, every positive increase between consecutive prices can contribute to the total profit.

Example:
Example: [1,5,3,6] gives profit from 1 to 5 and 3 to 6.


========================================
DSA TOPIC: Merge Intervals
========================================

Explanation:
Merge intervals combines overlapping ranges into larger non-overlapping ranges. Intervals are usually sorted by starting position before processing.

Example:
Example: [1,3] and [2,6] merge into [1,6].


========================================
DSA TOPIC: Interval Scheduling
========================================

Explanation:
Interval scheduling selects the maximum number of non-overlapping activities. A common greedy strategy sorts activities by finishing time.

Example:
Example: Activities finishing earlier leave more room for future activities.

Explanation:
A matrix is a two-dimensional data structure arranged using rows and columns. Matrix problems commonly involve traversal, searching, rotation, and transformations.

Matrix traversal visits elements row by row, column by column, or using another defined pattern. Nested loops are commonly used.

Transposing a matrix changes rows into columns. For a square matrix, elements across the main diagonal can be swapped.

Example:
Example: [[1,2],[3,4]] becomes [[1,3],[2,4]].


========================================
DSA TOPIC: Rotate Matrix
========================================

Explanation:
A square matrix can be rotated by first transposing it and then reversing each row. This provides an efficient in-place rotation technique.

Example: A 3x3 matrix can be rotated 90 degrees clockwise using these two operations.

DSA TOPIC: Spiral Matrix
========================================

Explanation:
Spiral traversal visits matrix elements from the outer boundary toward the center. Four boundaries can track the remaining unvisited region.

Example:
Example: A matrix is traversed top row, right column, bottom row, and left column repeatedly.


========================================
DSA TOPIC: Binary Search Tree
========================================

Explanation:
A Binary Search Tree follows the rule that values smaller than a node are placed in the left subtree and larger values are placed in the right subtree.

Example:
Example: In a BST with root 10, values 5 and 15 can appear on the left and right.


========================================
DSA TOPIC: BST Search
========================================

Explanation:
Searching a Binary Search Tree compares the target with the current node and chooses either the left or right subtree. Average complexity is O(log n) for a balanced tree.

Example:
Example: To find 15 from root 10, move to the right subtree.


========================================
DSA TOPIC: BST Insertion
========================================

Explanation:
BST insertion follows comparisons from the root until an empty position is found. The new value is inserted while maintaining the BST property.

Example:
Example: Inserting 7 into a tree containing 10 and 5 places 7 in the right subtree of 5.


========================================
DSA TOPIC: BST Deletion
========================================

Explanation:
BST deletion has three main cases: deleting a leaf, deleting a node with one child, and deleting a node with two children. The two-child case commonly uses an inorder successor.

Example:
Example: The inorder successor is the smallest value in the right subtree.


========================================
DSA TOPIC: Tree Height
========================================

Explanation:
The height of a tree represents the longest path from the root to a leaf, depending on the chosen height definition. Recursive traversal can calculate it.

Example:
Example: A tree with three levels has height 2 when height is counted by edges.


========================================
DSA TOPIC: Balanced Binary Tree
========================================

Explanation:
A balanced binary tree keeps subtree heights reasonably close so operations remain efficient. Large height differences can make tree operations approach O(n).

Example: A balanced tree divides values across left and right subtrees.

A heap is a complete binary tree that follows a heap-order property. In a min-heap the smallest element is at the root, while in a max-heap the largest is at the root.

Example: A min-heap can quickly provide the smallest element.


========================================
DSA TOPIC: Min Heap
========================================

Explanation:
A min-heap keeps the smallest value at the root. Insertion and deletion of the minimum generally take O(log n), while reading the minimum takes O(1).

Example:
Example: Adding 2 to a min-heap places it according to heap ordering.


========================================
DSA TOPIC: Max Heap
========================================

Explanation:
A max-heap keeps the largest value at the root. It is useful when repeatedly retrieving the largest element.

Example:
Example: A priority queue can use a max-heap to process the highest-priority value first.


========================================
DSA TOPIC: Priority Queue
========================================

Explanation:
A priority queue processes elements according to priority rather than insertion order. Heap structures are commonly used to implement priority queues efficiently.

Example:
Example: A task with higher priority can be removed before an older low-priority task.

========================================

Explanation:
Heap sort builds a heap and repeatedly extracts the appropriate extreme element. Its time complexity is O(n log n) and it can be performed with O(1) auxiliary space.

Example: A max-heap can repeatedly move the largest element to the end.
