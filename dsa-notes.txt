
========================================
DSA TOPIC: Array
========================================

Explanation:
An array is a linear data structure that stores elements in contiguous memory locations. Each element is accessed using an index. The first element is at index 0. Array access is O(1), while searching an unsorted array takes O(n).

Example:
Example: int[] arr = {10,20,30,40}; arr[2] gives 30.


========================================
DSA TOPIC: Array Traversal
========================================

Explanation:
Array traversal means visiting every element of an array one by one. A loop is commonly used to process each element. The operation takes O(n) time because every element may need to be visited.

Example:
Example: for each element in [10,20,30], process 10, then 20, then 30.


========================================
DSA TOPIC: Two Pointer Technique
========================================

Explanation:
The two pointer technique uses two indices to process an array or string efficiently. The pointers can move toward each other or in the same direction depending on the problem. It can reduce an O(n^2) approach to O(n) in many cases.

Example:
Example: In a sorted array, left starts at the beginning and right starts at the end.


========================================
DSA TOPIC: Sliding Window
========================================

Explanation:
Sliding window maintains a range of elements while moving through an array or string. Instead of repeatedly calculating the same range, the window is updated as it moves. This often gives O(n) solutions.

Example:
Example: For a fixed window size of 3, move the window one position at a time while updating its sum.


========================================
DSA TOPIC: Prefix Sum
========================================

Explanation:
A prefix sum stores cumulative sums of an array. It allows range-sum queries to be answered quickly after preprocessing. Building the prefix array takes O(n) time.

Example:
Example: For [2,4,6], the prefix sums are [2,6,12].


========================================
DSA TOPIC: Kadane Algorithm
========================================

Explanation:
Kadane's algorithm finds the maximum sum of a contiguous subarray. It keeps track of the best sum ending at the current position and the overall best sum. Its time complexity is O(n).

Example:
Example: In [-2,1,-3,4,-1,2,1], the maximum subarray is [4,-1,2,1].


========================================
DSA TOPIC: Binary Search
========================================

Explanation:
Binary search works on a sorted collection by repeatedly dividing the search space into two halves. If the target is smaller or larger than the middle value, one half is discarded. Time complexity is O(log n).

Example:
Example: Searching for 30 in [10,20,30,40,50] checks the middle before choosing the correct half.


========================================
DSA TOPIC: Linear Search
========================================

Explanation:
Linear search checks elements sequentially until the target is found or the array ends. It works even when the data is unsorted. Its worst-case time complexity is O(n).

Example:
Example: Searching for 30 in [10,20,30,40] checks 10, then 20, then 30.


========================================
DSA TOPIC: Sorting
========================================

Explanation:
Sorting arranges data according to a particular order, usually ascending or descending. Sorted data can make searching and other operations easier. Different sorting algorithms have different time and space requirements.

Example:
Example: [5,2,4,1] becomes [1,2,4,5] in ascending order.


========================================
DSA TOPIC: Bubble Sort
========================================

Explanation:
Bubble sort repeatedly compares adjacent elements and swaps them when they are in the wrong order. Larger elements gradually move toward the end. Its average and worst-case time complexity is O(n^2).

Example:
Example: During one pass, the largest unsorted element moves to the right side.


========================================
DSA TOPIC: Selection Sort
========================================

Explanation:
Selection sort repeatedly finds the smallest element from the unsorted portion and places it at the beginning. It performs O(n^2) comparisons and uses O(1) extra space.

Example:
Example: From [4,2,1,3], select 1 and place it at the first position.


========================================
DSA TOPIC: Insertion Sort
========================================

Explanation:
Insertion sort builds the sorted portion one element at a time. Each new element is inserted into its correct position among previously sorted elements. Its worst-case time complexity is O(n^2).

Example:
Example: It works similarly to arranging playing cards in your hand.


========================================
DSA TOPIC: Merge Sort
========================================

Explanation:
Merge sort divides an array into smaller parts, sorts those parts, and merges them. It follows the divide-and-conquer approach. Its time complexity is O(n log n) and it normally requires O(n) extra space.

Example:
Example: [4,1,3,2] is divided into smaller arrays and then merged in sorted order.


========================================
DSA TOPIC: Quick Sort
========================================

Explanation:
Quick sort selects a pivot and partitions the array so that smaller values go to one side and larger values go to the other. The partitions are then sorted recursively. Average time complexity is O(n log n).

Example:
Example: With 5 as pivot, values smaller than 5 are placed before it.


========================================
DSA TOPIC: Hashing
========================================

Explanation:
Hashing maps keys to locations using a hash function. Hash tables provide average O(1) insertion, deletion, and lookup. Hashing is useful for frequency counting and fast membership checking.

Example:
Example: A HashSet can quickly determine whether a value already exists.


========================================
DSA TOPIC: HashSet
========================================

Explanation:
A HashSet stores unique elements and does not allow duplicates. It uses hashing internally and provides average O(1) lookup, insertion, and deletion.

Example:
Example: Adding 10 twice to a HashSet still leaves only one 10.


========================================
DSA TOPIC: HashMap
========================================

Explanation:
A HashMap stores data as key-value pairs. It is commonly used for frequency counting, lookup tables, and mapping relationships. Average insertion and lookup are O(1).

Example:
Example: map.put("apple",3) stores apple with frequency 3.


========================================
DSA TOPIC: String
========================================

Explanation:
A string is a sequence of characters. Strings are widely used in pattern matching, searching, parsing, and many interview problems. In Java, String objects are immutable.

Example:
Example: String s = "hello" contains five characters.


========================================
DSA TOPIC: StringBuilder
========================================

Explanation:
StringBuilder is used to create and modify strings efficiently. Unlike String, it is mutable, so repeated modifications do not require creating many new String objects.

Example:
Example: StringBuilder can append characters repeatedly while constructing a result.


========================================
DSA TOPIC: Palindrome
========================================

Explanation:
A palindrome is a sequence that reads the same from both directions. A common method uses two pointers starting from opposite ends and compares characters.

Example:
Example: "level" is a palindrome because it reads the same forward and backward.


========================================
DSA TOPIC: Anagram
========================================

Explanation:
Two strings are anagrams when they contain the same characters with the same frequencies, possibly in different orders. Frequency arrays or hash maps can be used to check anagrams.

Example:
Example: "listen" and "silent" are anagrams.


========================================
DSA TOPIC: Frequency Counting
========================================

Explanation:
Frequency counting records how many times each value or character occurs. HashMap or arrays are commonly used for this technique. It can turn repeated searching into a single pass.

Example:
Example: In [1,2,2,3,3,3], the frequency of 3 is 3.
