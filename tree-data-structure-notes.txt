
What is a Tree
Explanation: A tree is a non-linear data structure made of nodes connected by edges. It starts from one root node and branches into smaller nodes.
Example: Example: 1 has children 2 and 3.

Root Node
Explanation: The root is the topmost node of a tree. A tree normally has only one root node.
Example: Example: In 1 -> 2,3, node 1 is the root.

Parent Node
Explanation: A parent is a node that has one or more child nodes connected below it.
Example: Example: If 1 connects to 2 and 3, then 1 is the parent of 2 and 3.

Child Node
Explanation: A child is a node directly connected below another node.
Example: Example: If 1 has 2 as its child, then 2 is the child of 1.

Leaf Node
Explanation: A leaf node is a node that does not have any children.
Example: Example: In 1 -> 2,3, nodes 2 and 3 are leaves.

Internal Node
Explanation: An internal node is a node that has at least one child.
Example: Example: If 1 has children 2 and 3, node 1 is an internal node.

Edge
Explanation: An edge is the connection between two nodes in a tree.
Example: Example: The connection between 1 and 2 is one edge.

Path
Explanation: A path is a sequence of nodes connected through edges.
Example: Example: 1 -> 2 -> 5 is a path from 1 to 5.

Depth of Node
Explanation: Depth tells how far a node is from the root. The root normally has depth 0.
Example: Example: Root 1 has depth 0, its child 2 has depth 1.

Height of Tree
Explanation: Height is the maximum number of edges from the root to a leaf.
Example: Example: If the longest path is 1 -> 2 -> 4, the height is 2.

Height of Node
Explanation: The height of a node is the longest path from that node down to a leaf.
Example: Example: A leaf has height 0.

Subtree
Explanation: A subtree is a smaller tree formed from a node and all of its descendants.
Example: Example: If 2 has children 4 and 5, then 2 with 4 and 5 forms a subtree.

Ancestor
Explanation: An ancestor is any node that comes before another node on its path to the root.
Example: Example: For 4 in 1 -> 2 -> 4, nodes 1 and 2 are ancestors.

Descendant
Explanation: A descendant is a node that comes below another node in the tree.
Example: Example: If 1 -> 2 -> 4, then 2 and 4 are descendants of 1.

Degree of Node
Explanation: The degree of a node is the number of children it has.
Example: Example: If node 1 has three children, its degree is 3.

Degree of Tree
Explanation: The degree of a tree is the maximum degree of any node in that tree.
Example: Example: If the largest number of children of one node is 3, tree degree is 3.

Tree with One Node
Explanation: A tree can contain only one node. That node is both the root and a leaf.
Example: Example: Tree = 1.

Binary Tree
Explanation: A binary tree is a tree where every node can have at most two children.
Example: Example: Node 1 can have left child 2 and right child 3.

Left Child
Explanation: In a binary tree, the left child is the node connected on the left side of its parent.
Example: Example: If 2 is the left child of 1, then 1.left points to 2.

Right Child
Explanation: In a binary tree, the right child is the node connected on the right side of its parent.
Example: Example: If 3 is the right child of 1, then 1.right points to 3.

Full Binary Tree
Explanation: A full binary tree is a binary tree where every node has either 0 or 2 children.
Example: Example: A node cannot have only one child.

Complete Binary Tree
Explanation: A complete binary tree has all levels completely filled except possibly the last level, which is filled from left to right.
Example: Example: This structure is commonly used for heaps.

Perfect Binary Tree
Explanation: A perfect binary tree has every internal node with two children and all leaves at the same level.
Example: Example: A perfect tree with height 2 has 7 nodes.

Balanced Binary Tree
Explanation: A balanced tree keeps the heights of left and right subtrees reasonably close.
Example: Example: An AVL tree automatically maintains balance.

Skewed Tree
Explanation: A skewed tree is a tree where nodes mostly continue in one direction.
Example: Example: 1 -> 2 -> 3 -> 4 behaves almost like a linked list.

Binary Search Tree
Explanation: A Binary Search Tree keeps smaller values on the left and larger values on the right.
Example: Example: For root 5, values 2 and 3 can be on the left, while 7 and 8 can be on the right.

BST Search
Explanation: Searching in a BST compares the target with the current node and chooses left or right.
Example: Example: To find 7 in root 5, move right.

BST Insertion
Explanation: To insert into a BST, compare the new value with each node until an empty position is found.
Example: Example: Insert 6 into 5,7 by moving right from 5 and then left from 7.

BST Deletion
Explanation: BST deletion has three cases: deleting a leaf, deleting a node with one child, and deleting a node with two children.
Example: Example: A node with two children can be replaced by its inorder successor.

Inorder Traversal
Explanation: Inorder visits Left, Root, Right. In a BST, inorder traversal produces values in sorted order.
Example: Example: Tree 2 with children 1 and 3 gives 1,2,3.

Preorder Traversal
Explanation: Preorder visits Root, Left, Right.
Example: Example: Tree 1 with children 2 and 3 gives 1,2,3.

Postorder Traversal
Explanation: Postorder visits Left, Right, Root.
Example: Example: Tree 1 with children 2 and 3 gives 2,3,1.

Level Order Traversal
Explanation: Level order visits nodes level by level from top to bottom. It normally uses a queue.
Example: Example: Tree 1 with children 2,3 gives 1,2,3.

DFS on Tree
Explanation: Depth First Search goes deep into one branch before coming back. Preorder, inorder, and postorder are DFS traversals.
Example: Example: Recursive traversal naturally performs DFS.

BFS on Tree
Explanation: Breadth First Search visits nodes level by level. A queue is normally used.
Example: Example: Start with root, process its children, then their children.

Recursive Tree Traversal
Explanation: Recursion is commonly used for tree traversal because every subtree is itself a smaller tree.
Example: Example: Visit left subtree, process node, then visit right subtree.

Iterative Tree Traversal
Explanation: Tree traversal can also be done without recursion by using an explicit stack.
Example: Example: Iterative preorder traversal uses a stack to remember nodes.

Tree Node in Java
Explanation: A binary tree node in Java normally stores a value and references to left and right children.
Example: Example: int val; TreeNode left; TreeNode right;

Maximum Depth
Explanation: Maximum depth finds how many levels or edges exist in the longest root-to-leaf path.
Example: Example: 1 -> 2 -> 4 has maximum depth 2 when counting edges.
