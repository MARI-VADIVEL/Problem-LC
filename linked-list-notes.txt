
========================================
LINKED LIST THEORY: Linked List Introduction
========================================

Explanation:
A linked list is a linear data structure made up of nodes. Each node stores data and a reference to another node. Unlike arrays, linked-list nodes do not have to be stored in contiguous memory.

Example:
Example: 10 -> 20 -> 30 -> null


========================================
LINKED LIST THEORY: Node
========================================

Explanation:
A node is the basic building block of a linked list. In a singly linked list, a node contains data and a reference called next that points to the following node.

Example:
Example: A node containing 10 can point to the node containing 20.


========================================
LINKED LIST THEORY: Head
========================================

Explanation:
The head is a reference to the first node of a linked list. It is the starting point for traversing the list.

Example:
Example: head -> 10 -> 20 -> 30 -> null


========================================
LINKED LIST THEORY: Tail
========================================

Explanation:
The tail is the last node in a linked list. Its next reference is null in a standard singly linked list.

Example:
Example: In 10 -> 20 -> 30 -> null, 30 is the tail.


========================================
LINKED LIST THEORY: Next Pointer
========================================

Explanation:
The next pointer stores the reference to the next node. It allows individual nodes to form a connected sequence.

Example:
Example: If node 10 points to node 20, then node10.next refers to node20.


========================================
LINKED LIST THEORY: Singly Linked List
========================================

Explanation:
A singly linked list contains nodes where every node points only to the next node. Traversal normally happens from the head toward the tail.

Example:
Example: 10 -> 20 -> 30 -> null


========================================
LINKED LIST THEORY: Doubly Linked List
========================================

Explanation:
A doubly linked list contains two references in each node: previous and next. This allows traversal in both forward and backward directions.

Example:
Example: null <- 10 <-> 20 <-> 30 -> null


========================================
LINKED LIST THEORY: Circular Linked List
========================================

Explanation:
In a circular linked list, the last node points back to an earlier node, commonly the head, instead of pointing to null.

Example:
Example: 10 -> 20 -> 30 -> 10


========================================
LINKED LIST THEORY: Circular Doubly Linked List
========================================

Explanation:
A circular doubly linked list combines backward and forward links with circular connections. The tail points to the head and the head points back to the tail.

Example:
Example: 10 <-> 20 <-> 30 where the ends are connected.


========================================
LINKED LIST THEORY: Linked List Memory
========================================

Explanation:
Linked-list nodes can be stored at different memory locations. References connect these locations to create the logical sequence.

Example:
Example: Nodes may physically be separated in memory while logically representing 10 -> 20 -> 30.


========================================
LINKED LIST THEORY: Linked List Traversal
========================================

Explanation:
Traversal means starting at the head and following next references until the required node or the end of the list is reached.

Example:
Example: To find 30 in 10 -> 20 -> 30, visit 10, then 20, then 30.


========================================
LINKED LIST THEORY: Linked List Search
========================================

Explanation:
Searching a linked list normally requires sequential traversal because nodes do not support direct index-based access.

Example:
Example: Finding the fifth node requires moving through previous nodes.


========================================
LINKED LIST THEORY: Linked List Access
========================================

Explanation:
Accessing an element at a specific position in a linked list takes O(n) time because the list must usually be traversed from the head.

Example:
Example: Finding index 4 requires following four links first.


========================================
LINKED LIST THEORY: Insert At Beginning
========================================

Explanation:
Insertion at the beginning is efficient because the new node can point to the current head and then become the new head.

Example:
Example: 20 -> 30 becomes 10 -> 20 -> 30.
