
========================================
RECURSION THEORY: Recursion Basics
========================================

Explanation:
Recursion is a technique where a function calls itself to solve a smaller version of the same problem. Every recursive solution needs a condition that eventually stops the calls.

Example:
Example: factorial(n) can call factorial(n-1) until n reaches 1.


========================================
RECURSION THEORY: Base Case
========================================

Explanation:
The base case is the condition that stops recursion. Without a base case, the function continues calling itself and can cause a stack overflow.

Example:
Example: In factorial, n == 0 can be the base case returning 1.


========================================
RECURSION THEORY: Recursive Case
========================================

Explanation:
The recursive case is the part where a function calls itself with a smaller or simpler input.

Example:
Example: factorial(n) returns n * factorial(n-1).


========================================
RECURSION THEORY: Call Stack
========================================

Explanation:
Each recursive function call is stored on the call stack until that call finishes. The most recent call is completed first.

Example:
Example: factorial(3) creates calls for 3, 2, and 1 before returning.


========================================
RECURSION THEORY: Stack Overflow
========================================

Explanation:
A stack overflow occurs when recursion creates too many active function calls for the available call-stack memory. Missing base cases or very deep recursion can cause it.

Example:
Example: A function that calls itself forever eventually causes StackOverflowError in Java.


========================================
RECURSION THEORY: Direct Recursion
========================================

Explanation:
Direct recursion occurs when a function directly calls itself.

Example:
Example: function f() calls f() again inside its own body.


========================================
RECURSION THEORY: Indirect Recursion
========================================

Explanation:
Indirect recursion occurs when one function calls another function and that second function eventually calls the first function again.

Example:
Example: function A calls B, and B calls A.


========================================
RECURSION THEORY: Tail Recursion
========================================

Explanation:
Tail recursion occurs when the recursive call is the final significant operation performed by the function. Some languages can optimize it, although Java does not generally perform tail-call optimization.

Example:
Example: A recursive factorial can carry the accumulated result as a parameter.


========================================
RECURSION THEORY: Head Recursion
========================================

Explanation:
Head recursion occurs when the recursive call happens before the remaining work of the current function.

Example:
Example: A function recursively processes n-1 before printing n.


========================================
RECURSION THEORY: Tree Recursion
========================================

Explanation:
Tree recursion occurs when a function makes more than one recursive call, causing the call structure to branch like a tree.

Example:
Example: Naive Fibonacci calls fibonacci(n-1) and fibonacci(n-2).


========================================
RECURSION THEORY: Linear Recursion
========================================

Explanation:
Linear recursion means each function call makes at most one recursive call. The call structure forms a single chain.

Example:
Example: Factorial creates one recursive call for each smaller value.


========================================
RECURSION THEORY: Divide and Conquer
========================================

Explanation:
Divide and conquer divides a problem into smaller subproblems, solves them recursively, and combines their results.

Example:
Example: Merge sort divides an array into halves, recursively sorts them, and merges them.
