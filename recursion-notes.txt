
========================================
RECURSION THEORY: Recursion Basics
========================================

Explanation:
Recursion is a technique where a function calls itself to solve a smaller version of the same problem. Every recursive solution needs a condition that eventually stops the calls.

Example:
Example: factorial(n) can call factorial(n-1) until n reaches 1.


========================================
RECURSION THEORY: Base Case
========================================

Explanation:
The base case is the condition that stops recursion. Without a base case, the function continues calling itself and can cause a stack overflow.

Example:
Example: In factorial, n == 0 can be the base case returning 1.


========================================
RECURSION THEORY: Recursive Case
========================================

Explanation:
The recursive case is the part where a function calls itself with a smaller or simpler input.

Example:
Example: factorial(n) returns n * factorial(n-1).


========================================
RECURSION THEORY: Call Stack
========================================

Explanation:
Each recursive function call is stored on the call stack until that call finishes. The most recent call is completed first.

Example:
Example: factorial(3) creates calls for 3, 2, and 1 before returning.


========================================
RECURSION THEORY: Stack Overflow
========================================

Explanation:
A stack overflow occurs when recursion creates too many active function calls for the available call-stack memory. Missing base cases or very deep recursion can cause it.

Example:
Example: A function that calls itself forever eventually causes StackOverflowError in Java.


========================================
RECURSION THEORY: Direct Recursion
========================================

Explanation:
Direct recursion occurs when a function directly calls itself.

Example:
Example: function f() calls f() again inside its own body.


========================================
RECURSION THEORY: Indirect Recursion
========================================

Explanation:
Indirect recursion occurs when one function calls another function and that second function eventually calls the first function again.

Example:
Example: function A calls B, and B calls A.


========================================
RECURSION THEORY: Tail Recursion
========================================

Explanation:
Tail recursion occurs when the recursive call is the final significant operation performed by the function. Some languages can optimize it, although Java does not generally perform tail-call optimization.

Example:
Example: A recursive factorial can carry the accumulated result as a parameter.


========================================
RECURSION THEORY: Head Recursion
========================================

Explanation:
Head recursion occurs when the recursive call happens before the remaining work of the current function.

Example:
Example: A function recursively processes n-1 before printing n.


========================================
RECURSION THEORY: Tree Recursion
========================================

Explanation:
Tree recursion occurs when a function makes more than one recursive call, causing the call structure to branch like a tree.

Example:
Example: Naive Fibonacci calls fibonacci(n-1) and fibonacci(n-2).


========================================
RECURSION THEORY: Linear Recursion
========================================

Explanation:
Linear recursion means each function call makes at most one recursive call. The call structure forms a single chain.

Example:
Example: Factorial creates one recursive call for each smaller value.


========================================
RECURSION THEORY: Divide and Conquer
========================================

Explanation:
Divide and conquer divides a problem into smaller subproblems, solves them recursively, and combines their results.

Example:
Example: Merge sort divides an array into halves, recursively sorts them, and merges them.


========================================
RECURSION THEORY: Recursive Factorial
========================================

Explanation:
Factorial of n is the product of all positive integers from 1 to n. Recursion represents it as n multiplied by factorial of n-1.

Example:
Example: 5! = 5 × 4 × 3 × 2 × 1 = 120.


========================================
RECURSION THEORY: Recursive Sum
========================================

Explanation:
The sum of numbers from 1 to n can be expressed recursively by adding n to the sum of numbers from 1 to n-1.

Example:
Example: sum(5) = 5 + sum(4).


========================================
RECURSION THEORY: Recursive Power
========================================

Explanation:
A number can be raised to a power recursively by multiplying the base by the result for one smaller exponent.

Example:
Example: power(2,4) = 2 × power(2,3).


========================================
RECURSION THEORY: Recursive Fibonacci
========================================

Explanation:
Fibonacci defines each number using the two previous numbers. The naive recursive implementation creates many repeated calls and has exponential time complexity.

Example:
Example: fib(5) = fib(4) + fib(3).


========================================
RECURSION THEORY: Fibonacci Optimization
========================================

Explanation:
The repeated work in recursive Fibonacci can be avoided using memoization or dynamic programming. This reduces the time from exponential to linear when each state is calculated once.

Example:
Example: Store fib(0) through fib(n) so each value is computed once.


========================================
RECURSION THEORY: Recursive Countdown
========================================

Explanation:
A countdown is a simple example of recursion where the input decreases on every call until a base case is reached.

Example:
Example: countdown(3) processes 3, 2, 1, then stops.


========================================
RECURSION THEORY: Recursive Count Up
========================================

Explanation:
A function can count upward by first making a recursive call with a smaller value and then performing the output while returning.

Example:
Example: countUp(3) can produce 1, 2, 3.


========================================
RECURSION THEORY: Reverse String Recursively
========================================

Explanation:
A string can be reversed recursively by processing the remaining substring and then placing the current character in the appropriate position.

Example:
Example: "abc" becomes "cba".


========================================
RECURSION THEORY: Palindrome Recursion
========================================

Explanation:
A palindrome can be checked recursively by comparing characters at both ends and then checking the smaller inner range.

Example:
Example: "level" compares l with l, then e with e.


========================================
RECURSION THEORY: Recursive Array Traversal
========================================

Explanation:
An array can be traversed recursively by processing one index and calling the function for the next index.

Example:
Example: process index 0, then index 1, then continue until the array ends.


========================================
RECURSION THEORY: Recursive Array Sum
========================================

Explanation:
The sum of an array can be calculated recursively by adding the current element to the sum of the remaining elements.

Example:
Example: [1,2,3] can be calculated as 1 + sum([2,3]).


========================================
RECURSION THEORY: Recursive Maximum
========================================

Explanation:
The maximum value of an array can be found recursively by comparing the current element with the maximum of the remaining elements.

Example:
Example: [4,7,2] compares 4 with the maximum of [7,2].
